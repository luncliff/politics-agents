# Review Template

응답 구조 설계 단계에서 선택한 프로필에 맞는 블록을 사용한다. 공통 머리말을 먼저 쓰고, 프로필 블록을 잇는다.

## 공통 머리말

```markdown
### 검토 설정
- 기준: 더불어민주당 강령·당헌·당규·윤리규범 (NotebookLM)
- notebook: {제목} ({id})
- 선택 프로필: {균형형 | 정보검증형 | 메시지작성형}
- 선택 근거: {요청 맥락 한 줄}

### NotebookLM 근거
- question: {실제 질의}
- answer: {응답 요약}
- sources_used: {출처 제목 목록}
- 미확인: {근거 부족/검증 미흡 항목}
```

## 프로필 A — 균형형 (당원 관점 + 중립 관점)

```markdown
### 당원 관점
- {쟁점} — {강령/당규/윤리규범 근거}

### 중립 관점
- {쟁점} — {당적과 무관한 사실·절차·일반 기준}

### 관점이 갈리는 지점
- {항목} — 당원 관점: {요지} / 중립 관점: {요지}

### 윤리 리스크
- {위험 신호} — {청렴/이해충돌/품위/자료유출/성희롱 등 해당 축}

### 전체 판정
- {높음 | 중간 | 낮음} — {근거 요약}

### 수정 방향
- {삭제 또는 완화할 표현}
- {보강할 가치축 또는 근거}
```

## 프로필 B — 정보검증형 (Information / Evidence / Reference / Rationale)

```markdown
### Information
- {문서·질의에서 확인된 사실 진술} (출처: {위치})

### Evidence
- {규정 원문·조항·인용 근거}

### Reference
- {URL | notebook 인용 | PDF 해시·페이지}

### Rationale
- {Information이 Evidence와 어떻게 연결되는지의 근거}

### 당원 관점 / 중립 관점
- 당원 관점: {규정 기준 해석}
- 중립 관점: {당적과 무관한 사실 기준 해석}

### 미확인·확인 필요
- {확인되지 않은 항목과 확인 범위}
```

> 정보검증형은 최종 출력 전 `neutralize-report-language` 기준으로 평가형·추정형 표현을 사실 서술형으로 정리한다.

## 프로필 C — 메시지작성형 (표현 리스크 + 대체 문구)

```markdown
### 표현 리스크
- {문장/표현} — {혐오·모욕·과장·규정 충돌 등 사유}

### 규정 점검
- {해당 강령/당규/윤리규범 조항} — {부합 | 주의 | 충돌}

### 당원 관점 / 중립 관점
- 당원 관점: {당 메시지 기준}
- 중립 관점: {일반 수용자 기준}

### 대체 문구
- 원문: {문장}
- 대체: {짧은 대체 문구}

### 전체 판정
- {높음 | 중간 | 낮음}
```

## 세션 종합 (공통 말미)

```markdown
### 세션 종합 의견
- {세션 전체에서 반복되는 강점과 취약점}
```

> 마이그레이션 참고: 이전 `review-party-alignment` 템플릿의 `부합하는 지점`/`충돌하거나 약한 지점`은 균형형의 `당원 관점`/`중립 관점`과 `관점이 갈리는 지점`으로, `비교정당 참고점`은 사용자가 별도 노트북·출처를 제공할 때만 추가한다.
