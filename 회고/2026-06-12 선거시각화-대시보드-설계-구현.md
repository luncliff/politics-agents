## 시도한 것

- 선관위 공공데이터 기반 인터랙티브 선거 시각화 대시보드 요구사항 분석
- Brainstorming 스킬로 사용자 목적·레이아웃·차트 유형·데이터 전략 순차 결정
- Visual Companion(브라우저 목업)으로 레이아웃 옵션, 코호트 시각화, 지역 탐색 방식 비교
- Writing-plans 스킬로 11개 태스크 TDD 구현 계획 수립
- Subagent-driven-development 스킬로 태스크별 독립 서브에이전트 파견 + 2단계 리뷰(spec/quality)
- 모든 태스크 구현 완료 후 최종 코드 리뷰 및 XSS critical issue 수정

## 성공한 것

- 전체 설계~구현 파이프라인 완주: 브레인스토밍 → 스펙 → 계획 → 구현 → 리뷰 → 보안 수정
- 12 unit tests + 26 E2E tests (Playwright) 전부 통과
- 주요 컴포넌트 구현:
  - D3.js 코호트 추세선 (연령대별 정당 지지율 시계열)
  - 타임라인 네비게이션 (7개 선거 포인트)
  - 광역시도 지역 필터 (다중선택 오버레이)
  - 클릭 → 히트맵 디테일 패널
  - 사용자 입력 사건 마커 (localStorage 유지)
  - 차트 유형 설명 패널 ("이 차트에 대해")
- Static data pipeline: `보관함/다운로드/nec.go.kr/` → `data/elections/` → `src/data/elections/`
- 선관위 데이터 정규화 스크립트 (`scripts/normalize-nec-data.mjs`)
- `.agents/skills/fetch-nec-data/` 및 `.agents/skills/election-viz/` 스킬 정의 추가

## 막힌 것 / 다음에 해결

- **D3 오프라인 벤더링 미완**: jsDelivr CDN importmap 방식 사용 — 인터넷 없이는 동작 안 함. 향후 `esbuild` 또는 `rollup`으로 D3를 번들링하거나 단일 파일로 vendoring 필요.
- **이벤트 마커 날짜 보간 미완**: `interpolateX()`가 항상 타임라인 중간에 마커 배치. 실제 선거 날짜 기준 선형 보간 구현 필요 (`election.date` 파라미터 전달 구조 추가).
- **선관위 실제 데이터 미수집**: `data/elections/presidential/2022.csv`는 샘플 데이터. `fetch-nec-data.mjs` 스크립트는 scaffold 수준 — `korea-gov-scraper` 에이전트로 실제 다운로드 필요.
- **Visual Companion 서버 시작 실패**: Windows bash에서 `start-server.sh` 실행 시 exit 127. 향후 Windows 환경 호환성 확인 필요.
- **Playwright `--workers=1` 필요**: 병렬 실행 시 `ERR_CONNECTION_REFUSED` 발생. playwright.config.mjs에 `workers: 1` 고정 설정 추가 검토.

## 새로 알게 된 사이트·포맷·정책

- **선관위 공공데이터 포털**: `info.nec.go.kr` — 선거 결과 CSV/API 제공
- **선관위 Open API 문서**: `nec.go.kr/portal/bbs/list/B0000338.do`
- **D3 v7 ESM**: `https://cdn.jsdelivr.net/npm/d3@7/+esm` — import map 없이 직접 사용 가능
- **Playwright `toBeAttached()` vs `toBeVisible()`**: 빈 섹션(zero-height)은 `toBeAttached()`로만 검증 가능 — `min-height: 1px` CSS 추가로 해결
- **SVG `.cohort-line` degenerate path**: 단일 선거 데이터에서 `d3.line()`이 `M355,212.16Z` 생성 — `waitForSelector('.cohort-line', { state: 'attached' })` 필요
- **`node --test tests/unit/`**: 디렉토리 경로 불가 — `node --test tests/unit/*.mjs` 글로브 필요 (Node 24)

## 자동화 후보

- **skill**: `fetch-nec-data` — 선관위 포털 로그인 없이 공공 CSV 다운로드 + `collect` 스킬 연계 (이미 scaffold 생성, 실제 구현 필요)
- **skill**: `election-viz` — 데이터 갱신 후 대시보드 검증 자동화 (이미 생성)
- **agent**: `nec-data-normalizer` — 다양한 선관위 CSV 포맷(선거 유형별 컬럼 차이)을 정규 구조로 변환하는 전문 에이전트 (향후 실제 데이터 수집 시 필요)
- **task** (VS Code): `election-viz: serve` — `npm run serve`로 대시보드 로컬 실행 태스크 추가
- **task** (VS Code): `election-viz: test` — `npx playwright test --workers=1` 태스크 추가
- **hook**: `PreToolUse` — `scripts/fetch-nec-data.mjs` 실행 전 `보관함/다운로드/nec.go.kr/` 존재 여부 확인
