# Election Visualization Dashboard — Design Spec

## Overview

대한민국 중앙선거관리위원회 공공데이터를 기반으로, 최근 선거/투표 결과를 인터랙티브하게 시각화하는 단일 페이지 HTML 대시보드.

**핵심 원칙:**
- 정보의 시각화에만 집중 (분석·해석 없음, 절대 중립)
- 시각화 과정 자체에 대한 이해 지원 (차트 유형 설명 포함)
- 일반 시민이 접근 가능한 중립 데이터 뷰어

## Target Users

- 일반 시민·유권자: 내 지역구 결과, 연령대별 투표율, 정당별 득표 현황을 쉽게 파악
- 특정 분석 목적 없이 공개 정보를 자유롭게 탐색하는 사용자

## Scope: Elections Included

| 유형 | 연도 | 비고 |
|------|------|------|
| 대통령선거 | 2017, 2022, 2025 | 전국 단위 |
| 국회의원선거 (총선) | 2020, 2024 | 지역구 + 비례대표 |
| 전국동시지방선거 | 2018, 2022 | 광역·기초단체장, 광역·기초의원, 교육감 |
| 재·보궐선거 | 주요 건 (2021 서울시장 등) | 주목도 높은 단일 선거 |

## Architecture

```
선관위 공공데이터 (CSV/JSON)
       ↓ (일괄 다운로드 스크립트)
 보관함/다운로드/nec.go.kr/  (원본 보존, 수정 금지)
       ↓ (전처리 스크립트 → 정규화)
 data/elections/  (정규화된 로컬 데이터)
       ↓
 단일 HTML + D3.js (static file 참조, 서버 불필요)
```

### Data Pipeline

1. **수집**: 스크립트가 선관위 API/포털에서 CSV/JSON 일괄 다운로드
2. **보존**: `보관함/다운로드/nec.go.kr/`에 원본 + `.meta.json`
3. **전처리**: 원본 → `data/elections/` 정규 구조로 변환
4. **렌더링**: HTML이 `data/elections/` 직접 참조 (fetch 또는 inline)

### Data Structure

```
data/elections/
├── meta.json              # 선거 목록: [{id, type, date, name}, ...]
├── presidential/          # 대선
│   ├── 2017.csv
│   ├── 2022.csv
│   └── 2025.csv
├── assembly/              # 총선
│   ├── 2020.csv
│   └── 2024.csv
├── local/                 # 지방선거
│   ├── 2018.csv
│   └── 2022.csv
└── byelection/            # 재보선
    └── 2021-seoul-mayor.csv
```

정규화 CSV 컬럼: `region, sub_region, age_group, party, votes, turnout, total_voters`

## Core Visualization: Cohort Trend Line

**주 시각화 방식:** 코호트 추세선 (Bump / Line Chart)
- X축: 선거 (시간순)
- Y축: 정당 지지율 (%)
- 선: 연령 코호트별 (같은 세대가 나이 들며 추적)
- 사건마커: 사용자 입력 세로 점선

**포인트 클릭 시 디테일 패널:**
- 해당 시점의 연령×정당 히트맵 오버레이
- 수치 요약 (득표수, 투표율, 유효투표)
- "이 차트에 대해" — 현재 보이는 차트 유형 설명

## Interaction Design

| 사용자 행동 | 반응 |
|---|---|
| 타임라인 포인트 클릭 | 해당 선거 데이터로 전체 차트 갱신 |
| 지역 버튼 클릭 | 코호트 추세선이 해당 지역 데이터로 갱신 (다중선택→오버레이) |
| 추세선 포인트 클릭 | 디테일 패널에 히트맵 + 수치 요약 표시 |
| "사건 추가" 버튼 | 날짜+이름 입력 → 타임라인에 세로 점선 마커 표시 |
| 사건 마커 클릭 | 해당 사건 레이블 토글 / 삭제 옵션 |
| "이 차트에 대해" 토글 | 현재 보이는 차트 유형·읽는 법 설명 패널 열기/닫기 |

## Region Scope

- 광역시도 단위 (17개 시도)
- 버튼 UI로 선택, 다중 선택 시 오버레이 비교
- 향후 확장: 기초단체 드릴다운 (이번 스코프 밖)

## Event Markers (User-Driven)

- 시스템이 사전 정의하는 사건 없음 (중립 원칙)
- 사용자가 직접 입력: 날짜 + 사건명
- 타임라인 위 세로 점선으로 표시
- 추가/삭제/토글 가능
- 세션 내 유지 (localStorage 등으로 persist 가능)

## Chart Explanation Layer

모든 차트에 "이 차트에 대해" 토글 제공:
- 차트 유형 이름 (예: "꺾은선 그래프 / Line Chart")
- 읽는 법 (축이 무엇을 나타내는지, 색상 의미)
- 왜 이 방식인지 (코호트 추적에 적합한 이유)
- 시각화 방법론 설명만 — 데이터 해석은 절대 포함하지 않음

## Political Neutrality

- 정당 색상: 공식 CI 색상 사용 (임의 해석 색상 배제)
- 정당명: 선관위 등록 명칭 그대로
- "분석/해석" 텍스트 없음 — 오직 수치와 시각적 비교만 제공
- 차트 설명은 시각화 방법론에 한정
- 사건 마커: 사용자 입력만 허용

## Technology Stack

- **렌더링**: D3.js (SVG 기반 인터랙티브 차트)
- **구조**: 단일 HTML + CSS + JS (빌드 도구 최소화)
- **데이터**: 로컬 CSV/JSON static 참조
- **데이터 수집**: Node.js 또는 Python 스크립트
- **테스트**: 브라우저 자동화 (Playwright) + 유닛 테스트

## Agent / Skill Integration

**기존 활용:**
| 자원 | 용도 |
|---|---|
| `korea-gov-scraper` agent | 선관위 포털 네비게이션, 데이터 다운로드 자동화 |
| `collect` skill | 다운로드 파일을 `보관함/다운로드/`에 보존 + 메타 기록 |

**신규 추가:**
| 이름 | 유형 | 역할 |
|---|---|---|
| `fetch-nec-data` | Skill | 선관위 API/포털에서 특정 선거 데이터 일괄 다운로드 + 정규화 |
| `election-viz` | Skill | 데이터 갱신 후 HTML 시각화 프리뷰 (dev server 기동) |
| `nec-data-normalizer` | Agent | 다양한 선관위 CSV/JSON 포맷을 정규 구조로 변환하는 전문 에이전트 |

## Out of Scope (Future)

- 기초단체 드릴다운
- 실시간 API 연동
- 비례대표 의석 배분 시뮬레이션
